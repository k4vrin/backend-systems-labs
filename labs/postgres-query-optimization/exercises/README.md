# Exercises

Work through these in order. Each exercise is designed around an unaided prediction, measured evidence, one justified change, and a changed-parameter check.

| Exercise | Capability | Status |
| --- | --- | --- |
| [01 — Selective lookup](01-selective-lookup/README.md) | Connect filtering and ordering to composite-index design | Available |
| 02 — Broad filter | Explain why PostgreSQL may prefer a sequential scan | Planned |
| 03 — Composite order | Choose column order from the workload | Planned |
| 04 — Expensive sort | Identify and reduce avoidable sort work | Planned |
| 05 — Bad join | Diagnose join strategy and repeated work | Planned |

Do not browse `solutions/` until the corresponding exercise tells you to compare your attempt.
